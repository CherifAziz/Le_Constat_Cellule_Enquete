Baromètre d’opinion de la Drees - Vague 2025
Diffusion des données
3 juillet 2026
Quelques remarques :
1. Correction de 3 variables
— Variable identifiant : "ident"
La variable ’ident’ permettant d’identifier les individus a été harmonisée en 2022 pour
être sur le même nombre de positions quelle que soit l’année d’enquête et est de type
caractère.
— Variable nombre d’enfants : "sdnbenf"
La variable sdnbenf était erronée avant 2012 et a donc été corrigée sur les années
précédant 2012.
— Variable pays de naissance : "sdpnais"
Cette variable présentait des incohérences sur les années 2008 à 2012 et donc a été
corrigée sur cette période.
2. Personne de référence
A partir de 2022, l’évolution du codage de la personne de référence crée une rupture de
série pour les variables liées à la personne de référence (sdprpcs7, sdprsitua, ...)
3. Autres remarques
Sont mis à disposition les fichiers (au format csv) historiques des deux dernières années
d’enquête dans la mesure où certaines questions ne sont posées que les années paires, et
d’autres que les années impaires.
Par exemple, en 2025, dans le module "famille", il n’y a que deux questions posées (FA01 et
FA21), questions ‘socle’ posée tous les ans. Toutes les autres questions de ce module sont po-
sées en 2024 ; donc pour les analyser, il faudra utiliser le fichier barometre2000_2024_diff.csv.
A l’inverse, par exemple en 2024, il n’y a qu’une question sur la thématique du handi-
cap (HA01), question ‘socle’ posée tous les ans, tandis que toutes les autres questions de
ce module sont posées en 2025, donc pour les analyser, il faudra utiliser le fichier baro-
metre2000_2025_diff.csv.
